# Road Receipts Mobile

A native React Native / Expo app rebuilt from the [Road Receipts handover](https://github.com/whyteaz/road-receipts-handover), pinned to commit `3b64312`. It keeps the supplied Manrope typography, pastel surfaces, exact product copy, native navigation icon morphs, and Gemini “Living intelligence” animation.

This repository contains the mobile client. It connects to the existing [GCP review backend](https://github.com/Lorem-Ipsum-AI-Builder-Cup-2026/prototype); no backend deployment is needed for this UI rebuild.

## Run locally

Requires Node.js 22 and npm. iOS requires macOS/Xcode/CocoaPods; Android requires JDK 17, Android Studio and SDK 36.

```sh
git clone https://github.com/Lorem-Ipsum-AI-Builder-Cup-2026/drivereport-mobile.git
cd drivereport-mobile
npm ci
npm run ios                 # native development build and Simulator
# npm run android           # native Android development build
```

After installing the native development app:

```sh
npx expo start --dev-client --lan
```

Rebuild after changing native dependencies, config plugins or `app.json`. Native `ios/` and `android/` directories are generated by Expo and excluded from Git. The existing bundle identifier `com.example.safetycar.dev` is retained to preserve installed evidence and signing. Choose a team-owned identifier before distribution.

For a physical iPhone, connect/trust it, enable Developer Mode, sign into Xcode, configure your development team, and run `npx expo run:ios --device`. Keep the phone and Metro computer on the same Wi-Fi network and allow local-network access.

## App flow

- **Home:** start a foreground recording. The black recording screen has elapsed time, a static red indicator and an End recording action.
- **Analysis:** the original five-stage motion design. Demo mode simulates all five steps. Live mode shows actual upload progress, then waits for the server's single review response without inventing agent progress.
- **Review:** play original footage, seek to findings, include/exclude offences, and edit plate, vehicle type, date, time, location and description. Missing facts prevent opening a report draft. Personal details and vehicle model are optional.
- **WhatsApp:** open a draft for the case's jurisdiction; attach the original video separately. Opening WhatsApp does not mark a report sent. The user confirms sending, with an eight-second Undo and a lasting “Mark as not sent” action.
- **Impact:** filter by date, offence, plate and local reporting status. Sent and fine counters count distinct known plates independently. Live authority outcomes remain unknown because the server does not provide them.
- **Developer:** import MP4/MOV/WebM files up to 300 MB, configure the API connection, retry retained clips or run a clearly labelled synthetic demo.
- **Settings:** jurisdiction-specific recipients, optional reporter details, locale and reduced motion. Profile details are opt-in for WhatsApp and are never sent to the analysis API.

The initial screen is always Home. Previous DriveReport evidence remains in local storage and completed reviews migrate into the new case model. Demo cases and real records remain separate. Simulator defaults to demo; a physical device defaults to live recording. Demo recording captures no camera footage, and demo findings are not real incidents.

## Recording and storage

There is no 60-second **session** limit. Silent 720p capture writes successive one-minute files until End recording. These files are internal segments, and starting the next file can introduce brief gaps; gapless recording is not claimed.

The app keeps the screen awake. Leaving the foreground, locking the phone, a camera error or low storage stops recording. Saved segments remain available in Developer. Footage is preserved; this flow does not automatically delete older recordings. Capture stops below 400 MiB of free storage. Long driving sessions therefore require available device space.

After recording ends, saved segments are analysed sequentially when credentials are configured. Without credentials they remain available for later analysis. This is post-drive review, not real-time violation detection. Retrying a partially completed job reuses completed cases and preserves user edits. An interrupted job can be retried after reopening the app.

## Backend connection

In **Developer → Backend settings**, enter an HTTPS base URL and Bearer access token, then save. Credentials use device SecureStore and are not committed or embedded in the app bundle.

The existing development base URL is `https://prototype-video-api-fydsujlsyq-uc.a.run.app`. “Check URL” calls `/health`; it does not validate the token.

The existing API contract is unchanged:

1. `POST /v1/uploads` with `mime_type` and `size_bytes`.
2. Binary `PUT` to the returned upload URL.
3. `POST /v1/review` with `video_uri` and `mime_type`.
4. Map the final response to per-vehicle cases while preserving citations and footage.

The backend limits clips to ten minutes and currently supplies Malaysia legal analysis only. Live review is gated to Malaysia. Other jurisdictions can be previewed with demo fixtures and configured recipients. There are no server APIs for persisted cases, progress events, tracking boxes, face blurring, authority submission, fine outcomes or remote deletion. Those capabilities are not fabricated in live mode. Keep the app open while reviewing; stopping local waiting cannot cancel an already-started server job.

Optional provisioning for contributors with existing GCP Secret Manager access:

```sh
npm run provision:ios
npm run provision:android
npm run provision:iphone -- <iphone-udid>
```

These scripts require authenticated `gcloud` access to `prototype-public-api-token` in project `aitech-good-s27493`; Android also needs `adb`, and iPhone provisioning needs `afcclient`. They transfer a temporary file into the development app's sandbox, which imports credentials into SecureStore and deletes the file. Release builds do not import it. Tokens are not printed. Public distribution requires user-scoped authentication and request limits in place of the shared development token.

## Motion implementation

Most UI is native React Native. Tab icons interpolate the supplied SVG matched-point geometry over 420 ms; pages, case switches and analysis rows use native-driver transitions. Home has a 3.2-second breathing treatment. Reduced motion respects both the app preference and the system setting.

Only the 230-point Living intelligence illustration uses a local WebView, to retain the authored Canvas renderer exactly: a bounded 72-particle field, at most 96 connections, a steady Gemini mark, and a settling receipt/check composition. Fonts, image, CSS and JavaScript are embedded locally; the view blocks external navigation and has a restrictive content security policy. Motion pauses outside the measured scroll viewport, in the background and in reduced-motion mode, and the illustration is destroyed when leaving the screen.

After changing its source assets, regenerate the embedded module:

```sh
npm run build:motion
```
